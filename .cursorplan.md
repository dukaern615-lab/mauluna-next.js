2. **Exact Design Match**: Every page, component, and layout must match 111.com exactly. No deviations.

3. **Functionality Parity**: All features from 111.com must work identically in Next.js.

4. **Supabase Integration**: Use Supabase for all backend operations. Do not use Prisma or other ORMs.

5. **Error Handling**: Always handle errors gracefully. Never leave infinite loading states.

6. **Code Quality**: Use TypeScript properly. Fix all type errors. Use proper Next.js conventions.

7. **Testing**: Test every page and feature before marking as complete.
